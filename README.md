# 📱 छोटे व्यापारियों के लिए दैनिक हिसाब-किताब (Daily Ledger & Cashbook)

यह एक डिजिटल **"खाता बुक"** वेब एप्लीकेशन है जिसे विशेष रूप से छोटे व्यापारियों (जैसे किराना दुकान, हार्डवेयर स्टोर, या लोकल वेंडर्स) के लिए बनाया गया है। यह ऐप हाथ से लिखी जाने वाली उधारी डायरी और पेन-कॉपी के झंझट को पूरी तरह समाप्त करता है।

## 🌟 मुख्य विशेषताएं (Features)
* **डिजिटल खाता प्रबंधन:** ग्राहकों के नाम और फोन नंबर के साथ डिजिटल प्रोफाइल।
* **सटीक जमा-उधारी ट्रैक:** लाल रंग में कुल उधारी (You Gave) और हरे रंग में कुल जमा (You Got) का साफ डिस्प्ले।
* **दैनिक रिकवरी डैशबोर्ड:** आज कुल कितना कैश कलेक्ट हुआ, इसका रियल-टाइम डेटा।
* **स्मार्ट व्हाट्सएप रिमाइंडर (1-Click WhatsApp):** बिना नंबर सेव किए ग्राहक को सिंगल क्लिक में बकाया राशि का मैसेज भेजने की सुविधा।

## 🛠️ टेक स्टैक (Tech Stack)
* **Backend:** Python, Django
* **Frontend:** HTML5, Bootstrap 5 (Responsive Layout)
* **Database:** SQLite3

## ⚙️ इंस्टॉलेशन और सेटअप (Installation)

1. **रिपॉजिटरी क्लोन करें:**
   ```bash
   git clone https://github.com/kbulbul026-coder/ledger-project
   cd ledger-project
   ```

2. **डेटाबेस माइग्रेशन चलाएं:**
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

3. **लोकल सर्वर चालू करें:**
   ```bash
   python manage.py runserver
   ```
   अब अपने ब्राउज़र में `http://127.0.0` खोलें।
